# web

서울 25개 자치구의 청년 1인가구 생활 여건 점수를 지도로 보여주는 정적 웹페이지입니다.

빌드 도구, 프레임워크, 서버 없이 HTML, CSS, JavaScript만 사용합니다.

---

## 실행 방법

`web/index.html` 을 더블클릭해서 브라우저로 열면 됩니다. 서버를 띄울 필요가 없습니다.

데이터가 `web/data/data.js` 안에 들어 있고 `<script>` 로 불러오기 때문에, 파일로 바로 열어도(`file://`) 동작합니다.

탭은 주소 뒤에 붙여서 바로 열 수도 있습니다.

| 주소 끝 | 탭 |
|---|---|
| `index.html#infra` | 인프라 (기본) |
| `index.html#housing` | 주거비 |
| `index.html#transit` | 교통 |
| `index.html#total` | 통합 |

---

## 폴더 구조

```text
web/
├─ index.html          페이지 뼈대 (헤더, 탭, 지도 영역, 상세 패널, 순위 목록)
├─ css/
│  └─ style.css        스타일
├─ js/
│  ├─ config.js        탭별 점수 컬럼·설명·상세 지표 설정
│  ├─ color.js         점수 → 초록색 단계 변환
│  ├─ map.js           GeoJSON → SVG 지도 그리기
│  └─ main.js          화면 상태 관리, 렌더링 (마지막에 실행)
└─ data/
   └─ data.js          웹에서 쓰는 데이터 전부 (src/export_web_data.py 로 생성)
```

`index.html` 맨 아래에서 `data/data.js` → `config.js` → `color.js` → `map.js` → `main.js` 순서로 불러옵니다.
모듈(`import`)을 쓰지 않는 일반 스크립트라서 앞 파일에서 만든 변수와 함수를 뒤 파일에서 그대로 씁니다. **이 순서를 바꾸면 안 됩니다.**

## 데이터 흐름

```text
data/processed/seoul_youth_final_scores_2025.csv ─┐
data/processed/rent_trend_2021_2025.csv ──────────┼─ src/export_web_data.py ─→ web/data/data.js
data/raw/seoul.geojson.json ──────────────────────┘                                │
                                                                                    ▼
                                                              window.WEB_DATA 로 main.js 에서 사용
```

`data/` 폴더는 GitHub에 올라가지 않기 때문에, 웹에 필요한 결과만 모아 `web/data/data.js` 에 넣어 둡니다.
파일 내용은 `window.WEB_DATA = { ... };` 한 줄이고, 그 안에 세 가지가 들어 있습니다.

| 키 | 원본 | 내용 |
|---|---|---|
| `districts` | `seoul_youth_final_scores_2025.csv` | 자치구별 원지표, 정규화 값, 분야별 점수, 종합점수, 순위 (25행) |
| `rentTrend` | `rent_trend_2021_2025.csv` | 자치구별 환산월세 구간 변화액·변화율 (현재 화면에서는 사용하지 않음) |
| `boundary` | `seoul.geojson.json` | 자치구 경계. `properties.name` 이 `자치구명` 과 같음 |

각 행의 키는 CSV 컬럼명(한글)을 그대로 사용합니다. `data.js` 는 생성 파일이므로 직접 고치지 말고 스크립트로 다시 만듭니다.

### 분석 결과가 바뀌었을 때

분석 코드를 다시 돌려 `data/processed/` 가 갱신되면, 아래 명령으로 웹 데이터를 다시 만듭니다.

```text
python src/export_web_data.py
```

스크립트는 점수표의 자치구명이 경계 데이터에 모두 있는지 확인하고, 없으면 오류를 냅니다.

## 화면 동작

### 탭

탭을 누르면 해당 점수로 지도 색, 순위 목록, 상세 패널이 모두 다시 그려집니다.

| 탭 | 사용하는 컬럼 | 의미 |
|---|---|---|
| 인프라 | `인프라종합점수` | 편의점·슈퍼마켓, 버스정류소, 지하철역, 일상·종합 의료시설의 면적당 개수 평균 |
| 주거비 | `주거비점수` | 2025 환산월세가 낮고 2021년 대비 상승률이 낮을수록 높음 |
| 교통 | `교통점수` | 면적당 버스정류소·지하철역 수 평균 |
| 통합 | `종합점수` | 청년집중도·주거비·생활환경·교통·의료의 5개 영역 동일 가중 평균 |

점수는 0~1 값이며 화면에는 100을 곱해 소수 한 자리로 표시합니다 (예: `0.6179` → `61.8점`).

순위는 선택한 탭의 점수로 다시 매깁니다. 그래서 같은 구라도 탭마다 순위가 다릅니다.

### 지도 색

1. 선택한 탭에서 가장 낮은 점수를 0, 가장 높은 점수를 1로 놓고 각 구의 위치(`t`)를 계산합니다.
2. `color.js` 의 `greenAt(t)` 가 옅은 초록 → 중간 초록 → 진한 초록 세 색 사이를 섞어 색을 정합니다.
   - 색은 OKLab 색공간에서 섞어서 단계가 눈에 고르게 보이도록 했습니다.
   - 두 색만 섞으면 중간이 회색빛이 돌아서 채도 있는 중간 초록을 하나 넣었습니다.
3. 진한 칸에는 흰 글씨, 옅은 칸에는 짙은 초록 글씨를 씁니다 (`labelColorAt`).

즉 색은 **절대 점수가 아니라 그 탭 안에서의 상대 위치**입니다. 범례의 양 끝 숫자가 그 탭의 최저·최고 점수입니다.

### 지도 그리기

`map.js` 가 GeoJSON 좌표(경도, 위도)를 SVG 좌표로 바꿔 자치구마다 `<path>` 를 만듭니다.

- 서울 정도 범위는 지구 곡률이 거의 문제 되지 않아서, 위도에 맞춰 경도 폭만 보정한 단순 평면 투영을 사용합니다. 외부 지도 라이브러리는 쓰지 않습니다.
- 구 이름과 순위는 각 구 다각형의 면적 중심에 표시합니다.
- 이름이 겹치거나 한쪽으로 쏠리는 구(중구, 종로구, 용산구)는 `LABEL_NUDGE` 에서 위치를 손으로 조금 옮깁니다.

### 마우스·클릭

- 지도나 순위 목록에서 구에 마우스를 올리면 그 구에 검은 테두리가 생기고 오른쪽 상세 패널이 바뀝니다.
- 클릭하면 그 구가 고정됩니다. 같은 구를 다시 클릭하면 고정이 풀립니다.
- 아무 구도 선택하지 않았을 때는 상세 패널에 현재 탭 1위 구가 나옵니다.

## 자주 고칠 만한 것

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 탭 설명 문구, 상세 패널 지표 바꾸기 | `js/config.js` 의 `TABS` |
| 탭 추가하기 | `js/config.js` 에 항목 추가 + `index.html` 에 `<button class="tab" data-tab="...">` 추가 |
| 지도 색 바꾸기 | `js/color.js` 의 `STOPS` (옅은 색 → 진한 색 순서) |
| 구 이름 위치 조정 | `js/map.js` 의 `LABEL_NUDGE` (`[x 이동, y 이동]`, SVG 좌표 기준) |
| 기본으로 열리는 탭 | `js/config.js` 의 `DEFAULT_TAB` |

`config.js` 의 상세 지표 항목은 아래 형식입니다.

```js
{ label: "환산월세 2025", key: "환산월세_2025_만원", unit: "만원", digits: 1 }
// scale: 100 을 주면 값에 100을 곱해서 표시 (0~1 점수를 100점 기준으로 보여줄 때)
```

`key` 는 `districts` 데이터(= `seoul_youth_final_scores_2025.csv`)에 있는 컬럼명이어야 합니다.
