# 생활물가지수 정규화


## 1. 입력 데이터

- 입력 파일: `data/processed/seoul_youth_integrated_2025.csv`
- 사용 변수: `생활물가지수`
- 기준연도: 2025년
- 분석 단위: 서울시 25개 자치구

## 2. 정규화 방법

```text
정규화값 = (최댓값 - 현재값) / (최댓값 - 최솟값)
```

- 생활물가지수가 가장 낮은 자치구: 1
- 생활물가지수가 가장 높은 자치구: 0
- 결과는 소수점 넷째 자리까지 반올림.

## 3. 산출 변수

```text
생활물가지수_정규화
```

정규화 값이 1에 가까울수록 생활비 측면에서 유리한 지역으로 해석.

## 4. 예외 처리

- 모든 자치구의 값이 같으면 정규화 값을 0으로 처리.
