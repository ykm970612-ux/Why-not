# 최종 종합점수 산출 기준

## 1. 입력 데이터

- 입력 파일: `data/processed/seoul_youth_normalized_2025.csv`
- 실행 코드: `src/calculate_final_scores.py`
- 분석 단위: 서울시 25개 자치구
- 기준연도: 2025년


다음을 먼저 실행

```text
python src/create_normalized_table.py
```

---

## 2. 최종 점수 사용 지표

최종 종합점수에는 다음 9개 정규화 지표를 사용.

| 영역 | 사용 지표 | 해석 |
|---|---|---|
| 청년 집중도 | `청년1인가구_LQ_2025_정규화` | 높을수록 청년 1인가구 집중도가 높음 |
| 주거비 | `환산월세_2025_정규화` | 높을수록 환산월세 부담이 낮음 |
| 주거비 변화 | `월세변화율_정규화` | 높을수록 월세 상승 부담이 낮음 |
| 생활비 | `생활물가지수_정규화` | 높을수록 생활물가 부담이 낮음 |
| 생활편의 | `생활편의시설수_정규화` | 높을수록 면적당 생활편의시설이 많음 |
| 버스 교통 | `버스정류소수_정규화` | 높을수록 면적당 버스정류소가 많음 |
| 지하철 교통 | `물리적_역수_정규화` | 높을수록 면적당 지하철역이 많음 |
| 일상 의료 | `일상의료시설수_정규화` | 높을수록 면적당 일상의료시설이 많음 |
| 종합 의료 | `종합의료시설수_정규화` | 높을수록 면적당 종합의료시설이 많음 |

시설 관련 변수는 원래 시설수를 자치구 면적으로 나눈 1㎢당 시설수를 기준으로 정규화.

---

## 3. 가중치 적용 기준

최종점수는 청년집중도·주거비·생활환경·교통·의료의 5개 영역에
각각 20%의 동일 가중치를 적용한다.

```text
종합점수 =
(
청년집중도점수
+ 주거비점수
+ 생활환경점수
+ 교통점수
+ 의료점수
) ÷ 5
```

영역 안에 지표가 2개인 경우에는 두 지표의 평균을 해당 영역 점수로 사용한다.
따라서 청년집중도 지표의 최종 가중치는 20%이고, 나머지 8개 지표는 각각 10%다.

| 영역 | 영역 가중치 | 영역 내 지표 | 지표별 최종 가중치 |
|---|---:|---:|---:|
| 청년 집중도 | 20% | 1개 | 20% |
| 주거비 | 20% | 2개 | 각 10% |
| 생활환경 | 20% | 2개 | 각 10% |
| 교통 | 20% | 2개 | 각 10% |
| 의료 | 20% | 2개 | 각 10% |

인프라 종합점수는 지역 해석과 월세 대비 인프라 분석에 사용하는 참고 점수이며,
최종점수에 별도의 여섯 번째 영역으로 중복 반영하지 않는다.

100점 기준 점수는 다음과 같이 계산.

```text
종합점수_100점 = 종합점수 × 100
```

결과는 소수점 둘째 자리까지 반올림.

## 4. 영역별 점수

지역별 특성을 쉽게 해석하기 위해 다음 영역별 점수를 별도로 계산.

### 청년집중도점수

```text
청년집중도점수 = 청년1인가구_LQ_2025_정규화
```

### 주거비점수

```text
주거비점수 =
(환산월세_2025_정규화 + 월세변화율_정규화) ÷ 2
```

### 생활환경점수

```text
생활환경점수 =
(생활물가지수_정규화 + 생활편의시설수_정규화) ÷ 2
```

### 교통점수

```text
교통점수 =
(버스정류소수_정규화 + 물리적_역수_정규화) ÷ 2
```

### 의료점수

```text
의료점수 =
(일상의료시설수_정규화 + 종합의료시설수_정규화) ÷ 2
```


## 5. 인프라 종합점수

월세 대비 생활 인프라를 분석하기 위해 다음 5개 지표의 평균을 인프라 종합점수로 사용.

```text
인프라종합점수 =
(
생활편의시설수_정규화
+ 버스정류소수_정규화
+ 물리적_역수_정규화
+ 일상의료시설수_정규화
+ 종합의료시설수_정규화
) ÷ 5
```

인프라 종합점수가 높을수록 자치구 면적 대비 생활·교통·의료시설이 상대적으로 풍부한 지역으로 해석.
