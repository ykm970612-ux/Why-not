## 3. 정규화 방법

### 정방향 Min-Max 정규화

값이 높을수록 유리한 지표에 적용.

```text
정규화값 = (현재값 - 최솟값) / (최댓값 - 최솟값)
```

적용 지표:

- 청년 1인가구 LQ
- 버스정류소 수
- 물리적 지하철역 수
- 일상의료시설 수
- 종합의료시설 수
- 생활편의시설 수

### 역방향 Min-Max 정규화

값이 낮을수록 유리한 지표에 적용.

```text
정규화값 = (최댓값 - 현재값) / (최댓값 - 최솟값)
```

적용 지표:

- 2025년 환산월세
- 2021~2025년 월세변화율
- 생활물가지수

정규화 결과는 소수점 넷째 자리까지 반올림.
