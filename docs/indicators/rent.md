# 환산월세 정규화

## 1. 목적

2025년 서울시 자치구별 환산월세를 동일한 0~1 범위로 변환하여 종합지표 산출에 사용.

환산월세는 낮을수록 청년 1인가구의 주거비 부담이 적으므로 역방향 Min-Max 정규화 적용.

## 2. 입력 데이터

- 입력 파일: `data/processed/seoul_youth_integrated_2025.csv`
- 사용 변수: `환산월세_2025_만원`, `변화율_2021_2025_퍼센트`
- 기준연도: 2021년, 2025년
- 분석 단위: 서울시 25개 자치구

## 3. 정규화 방법

```text
정규화값 = (최댓값 - 현재값) / (최댓값 - 최솟값)
```

- 환산월세가 가장 낮은 자치구: 1
- 환산월세가 가장 높은 자치구: 0
- 결과는 소수점 넷째 자리까지 반올림.

## 4. 산출 변수

```text
환산월세_2025_정규화, 월세변화율_정규화
```

정규화 값이 1에 가까울수록 주거비 측면에서 유리한 지역으로 해석.

## 5. 월세 변화율 활용

`환산월세_2021_만원`과 `환산월세_2023_만원`은 월세 변화 추이를 확인하기 위한 원자료로 사용하며 별도로 정규화하지 않음.

두 정규화 값은 1에 가까울수록 청년 1인가구에 유리한 것으로 해석.
