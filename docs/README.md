## 버스정류소 전처리 기준

| 항목 | 전처리 기준 |
|---|---|
| 원본 데이터 | `bus_stops_2025_seoul.xlsx` |
| 자치구 분류 | 정류소 위도·경도 좌표와 `seoul.geojson.json` 경계 활용 |
| 좌표 검증 | 경도 124~132, 위도 33~39 |
| 경계 처리 | `within`으로 분류 후 미분류 좌표는 `intersects`로 재검사 |
| 중복 처리 | 공간 결합 과정의 중복만 제거, 원본 중복 행은 유지 |
| 집계 기준 | 자치구별 분류 성공 정류소 행 수 |
| 제외 대상 | 좌표 오류 및 자치구 미분류 데이터 |

## 지하철역 전처리 기준

| 항목 | 전처리 기준 |
|---|---|
| 원본 데이터 | `subway_stations_2025_seoulmetro.csv` |
| 자치구 분류 | 도로명주소에서 자치구명 추출 |
| 자치구 검증 | GeoJSON의 서울시 25개 자치구와 대조 |
| 역명 정리 | 역명 내 공백 제거 |
| 중복 처리 | 동일 자치구·동일 역명은 1개 물리적 역으로 집계 |
| 집계 기준 | 환승역 중복 제거 후 자치구별 물리적 역 수 |
| 제외 대상 | 주소에서 자치구를 확인할 수 없거나 경계 목록과 불일치하는 데이터 |

## 3. Min-Max 정규화

| 항목 | 적용 기준 |
|---|---|
| 정규화 대상 | 자치구별 버스정류소 수 및 지하철역 수 (각각 별도 계산) |
| 정규화 방식 | `(X - X_min) / (X_max - X_min)` |
| 정규화 범위 | 0~1 |
| 반올림 | 소수점 다섯째 자리에서 반올림해 넷째 자리까지 저장 (`round(4)`) |
| 예외 처리 | 최댓값과 최솟값이 같으면 0으로 처리 |
