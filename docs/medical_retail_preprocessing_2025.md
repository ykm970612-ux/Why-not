# 의료·생활편의시설 전처리 (2025)

## 범위와 기준

- 분석 단위: 서울 25개 자치구, `자치구명`을 연결 키로 사용하며 자치구별 한 행.
- 의료는 **2025-12-31 기준** 요양기관 현황을 사용한다. 기준일에 등록된 기관 중 2025년 이전에 개설한 기관도 포함한다. 청년의 일상 의료 여건과 병원 공급을 구분해 두 지표를 산출한다.
- 생활편의: **2025년 4분기(20254)** 점포 수. 의료의 연말 기준에 맞춘 선택이며 연간 합계·연평균이 아니다. 팀의 별도 합의가 확인되지 않아 적용 근거를 이 문서에 기록한다. 팀 공유 시 이 시점과 변수 범위를 확인한다.
- 청년 20~39세 조건은 시설 집계에 적용하지 않는다. 연령별 이용·접근성 지표는 산출하지 않는다.
- **사용자 지시에 따라 인구·면적 보정은 이번 담당 작업에서 제외**한다. 다른 담당자가 합의한 2025년 분모를 연결할 때 보정한다. 보정값을 0이나 임의의 분모로 생성하지 않는다.

사용자가 제공한 Downloads 파일을 사용했으며 별도 최신 파일로 대체하지 않았다. 출처 페이지 확인일은 2026-11-07이고 실제 다운로드 일자는 확인할 수 없다. 의료의 기준일은 제공 파일명에 근거한다. 의료 원본은 104,775행, 상권 원본은 54,765행이다. 상권 원본에는 2021~2026년이 섞여 있지만 결과에는 20254만 들어간다. 원본 보관명에 있는 2025는 이 작업의 분석연도를 뜻하며 원본 전체가 2025년이라는 의미는 아니다.

Downloads 원본(CP949)은 수정하지 않았다. `data/raw/`에는 **내용·행·열을 그대로 유지하고 UTF-8-SIG로 인코딩만 변환한 복사본**을 지정 이름으로 보관했다. 디코딩한 전체 텍스트 일치도 확인했다. 원본과 복사본의 파일명·인코딩·SHA-256은 `data/raw/facilities_source_manifest_2025.json`에 기록했다. `data/` 전체는 기존 `.gitignore`에 의해 Git 업로드 대상에서 제외된다.

## 처리 방법

1. UTF-8-SIG, CP949 순으로 읽고 필수 열과 CSV 열 수를 검사한다. 결측 필수값을 임의로 0으로 대체하지 않는다.
2. 의료에서 `시도명=서울특별시`만 선택한다. 자치구명은 공백 및 서울특별시/서울시 접두사를 정리하고 정해진 25개 명칭과 대조한다.
3. 의료는 모든 필드가 같은 행만 중복 제거한다. 동일 내용에 식별자만 다른 경우는 자동 집계하지 않고 오류로 중단한다. 개설일 형식과 2025-12-31 이하 여부를 검증한다. 원본의 오래된 개설일은 시설 수에 영향을 주지 않으므로 유지한다.
4. 의료를 자치구·요양종별로 센 뒤, 각 지표에 해당하는 세 종별만 합산한다. 한의원, 요양병원, 조산원, 보건지소 등은 원본 검증 범위에 포함하고 지표 산식에서는 제외한다. 지표에 해당하는 기관이 없는 구에는 0을 기록한다. 원본에서 자치구 자체가 빠져 있으면 오류다.
5. 상권에서 `기준_년분기_코드=20254`와 `CS300001(슈퍼마켓)`, `CS300002(편의점)`만 선택한다. 두 업종은 생활편의시설의 조작적 정의이며 대형마트 전체를 대표하지 않는다.
6. 자치구·업종별 한 행인지 확인하고 숫자의 쉼표·공백·단위 문자를 제거해 정수로 변환한다. 음수·비정수·비유한값은 오류다. `전체_점포_수=일반_점포_수+프랜차이즈_점포_수`를 대조한다. 전체 점포 수에 프랜차이즈 수를 다시 더하지 않는다.
7. 모든 구에서 두 업종이 존재하는지 검사한다. 빠진 행을 0으로 추정하지 않는다. 분기별 점포 수를 합산하면 중복 계상이 발생하므로 다른 분기를 더하지 않는다.
8. 주요 지표에 자치구 간 1.5×IQR 이상치 검사를 적용한다(사분위수: inclusive). 시설 집중 자체가 분석 대상이므로 통계적 이상치는 표시만 하고 삭제·상한 처리를 하지 않는다.
9. 모든 검증 후 자치구 가나다순으로 UTF-8-SIG CSV를 저장한다. 상세 검증 결과는 `data/processed/facilities_validation_2025.json`에 저장한다.

## 산출 변수

`medical_facilities_clean_2025.csv`:

| 컬럼 | 정의 / 단위 |
|---|---|
| 자치구명 | 서울 25개 자치구, 유일한 연결 키 |
| 기준연도, 기준월, 기준일 | 2025, 12, 31 (정수) |
| 일상의료시설수 | 의원수 + 치과의원수 + 약국수 / 개 |
| 종합의료시설수 | 상급종합병원수 + 종합병원수 + 병원수 / 개. `병원`은 원본 요양종별의 명칭을 그대로 적용한다. |

`retail_stores_clean_2025.csv`:

| 컬럼 | 정의 / 단위 |
|---|---|
| 자치구명 | 서울 25개 자치구, 유일한 연결 키 |
| 기준연도, 기준분기 | 2025, 4 (정수) |
| 편의점수 | CS300002의 전체 점포 수 / 개 |
| 슈퍼마켓수 | CS300001의 전체 점포 수 / 개 |
| 생활편의시설수 | 편의점수 + 슈퍼마켓수 / 개 |

두 CSV에서 `자치구명` 외 컬럼은 모두 정수다. CSV 자체는 형식 메타데이터가 없으므로 로드 시 수치형으로 해석한다. 병합 시 두 파일의 `기준연도` 중복 컬럼은 하나만 남긴다. 공급량 집계로서 시설의 질·진료시간·보행 접근성·진료과 적합성을 의미하지 않는다.

## 실행 결과와 데이터 품질

- 의료 원본의 서울 25,405행을 검증했다. 25개 구를 합산하면 일상의료시설은 21,129개, 종합의료시설은 294개다.
- 상권: 20254 전체 2,495행 중 두 업종 50행 → 25개 구, 생활편의시설 22,032개.
- 선택 범위의 필수값 결측 0건, 의료 완전 중복 0건. 상권 자치구·업종 중복 및 업종 누락 없음. 각 결과는 25행이며 자치구 키가 유일하다.
- **의료 암호화 식별자 한 값이 서로 다른 165개 기관에 반복된다.** 식별자로 중복 제거하지 않고 서로 다른 내용의 행을 보존했다. 기관 단위 추가 연결에는 식별자를 단독 키로 사용하지 않는다.
- 개설일 최솟값 1900-01-01, 최댓값 2025-12-30. 1950년 이전 개설일 8행을 표시해 유지했다. 날짜 신뢰성 확인이 필요한 값이며 연말 시설 수 집계에서는 제외 근거로 사용하지 않았다.
- IQR 검사에서 일상의료시설수는 강남구 3,185개, 서초구 1,587개, 송파구 1,395개가 표시됐다. 종합의료시설수와 생활편의시설수는 강남구가 각각 39개, 1,663개로 표시됐다. 해당 값은 결과에 유지했다.

## 재현과 제출

Python 3.12.9에서 실행했으며 외부 패키지·API 키는 필요 없다. 저장소 루트에서:

```powershell
python src/healthnconv_preprocess_facilities.py
python -m unittest discover -s tests -p "*test_preprocess_facilities.py" -v
```

Downloads의 CP949 파일을 직접 읽는 것도 가능하다(원본 변경 없음):

```powershell
python src/healthnconv_preprocess_facilities.py --medical-input "C:/Users/Buge7/Downloads/건강보험심사평가원_요양기관 개설 현황_20251231.csv" --retail-input "C:/Users/Buge7/Downloads/서울시 상권분석서비스(점포-자치구).csv"
```
