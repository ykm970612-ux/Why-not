1. 사용한 데이터
    행정안전부 주민등록인구통계에서 2021년, 2023년, 2025년 연령별 거주자 인구 데이터를 받았음.

서울 25개 자치구의 20~39세 청년 인구와 전체 인구를 정리했다.
    - 출처: 행정안전부 주민등록인구통계 (연령별 인구현황)
    - 연도: 2021, 2023, 2025
    - 지역: 서울특별시 25개 자치구
    - 청년 기준: 20~39세 (20~29세 + 30~39세)
    - 인구 기준: 거주자

원본 파일
    - data/raw/youth_population_2021.csv
    - data/raw/youth_population_2023.csv
    - data/raw/youth_population_2025.csv
2. 전처리한 내용
    1. 원본 CSV를 cp949로 불러왔다.
    2. 행정구역, 20~29세, 30~39세, 총인구수 컬럼만 선택했다.
    3. 행정구역에서 서울특별시로 시작하고 구 (가 포함된 행만 남겼다. 서울시 전체 합계 행은 제외했다.
    4. 인구수에 들어 있는 쉼표(,)를 제거하고 숫자형으로 변환했다.
    5. 20~29세와 30~39세를 더해 청년인구 컬럼을 만들었다.
    6. 행정구역에서 종로구, 중구처럼 자치구 이름만 추출했다.
    7. 연도별 컬럼명에 _2021, _2023, _2025를 붙였다.
    8. 자치구명을 기준으로 3개 연도 데이터를 병합했다.
    
    전처리 코드는 src/youth_population.py에 있다.

3. 최종 데이터
- 파일: data/processed/youth_population_clean.csv
- 인코딩: utf-8-sig
- 크기: 25행 × 7열
- 기준 컬럼: 자치구명

4. 확인한 내용
- 서울 25개 자치구가 나오는 것 확인
- 결측치 0개
- 자치구명 중복 0개
- 인구수 컬럼 6개 모두 int64
- 저장한 CSV를 다시 불러왔을 때 (25, 7) 확인
- 저장 전후 데이터를 비교했을 때 값 차이 없음

CSV를 다시 읽으면 자치구명 자료형이 object에서 str로 바뀌어서 equals()는 False가 나왔습니다. 실제 데이터 값은 동일해서 무시했습니다.

5. 주의사항 
청년 인구는 행정안전부 주민등록 거주자 기준이고, 청년 1인 가구는 KOSIS 인구총조사 기준입니다. 자료 기준이 달라서 나중에 두 데이터를 합쳐 비율을 계산할 때는 주의해야 함

원본 자료의 정확한 기준일은 별도로 확인해야 할 것 같습니다.
