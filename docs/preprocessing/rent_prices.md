# 전월세 데이터 전처리 

## 1. 사용 데이터

| 기준연도 | 원본 파일명 | 파일 형식 | 인코딩 |
|---:|---|---|---|
| 2021 | `rent_transactions_2021_seoul.txt` | 텍스트 파일 | `cp949` |
| 2023 | `rent_transactions_2023_seoul.csv` | CSV | `utf-8-sig` |
| 2025 | `rent_transactions_2025_seoul.csv` | CSV | `cp949` |

---

## 2. 분석 단위

- 지역 : 서울시 25개 자치구
- 시간 : 2021년, 2023년, 2025년
- 대상 계약 : 월세 계약
- 주택 규모 : 임대면적 60㎡ 이하

---

## 3. 전처리 기준



- `계약연도`가 해당 기준연도와 일치.
- `전월세구분`이 `월세`인 계약만 사용.
- `임대면적`은 0㎡ 초과 60㎡ 이하만 사용.
- `보증금(만원)`은 0 이상만 사용.
- `임대료(만원)`는 0보다 큰 값만 사용.
- `자치구명`, `임대면적`, `보증금(만원)`, `임대료(만원)` 중 하나라도 결측치이면 제외.

`계약일`, `임대면적`, `보증금(만원)`, `임대료(만원)`은 숫자형으로 변환. 숫자로 변환할 수 없는 값은 결측치로 처리한 뒤 위 기준에 따라 제외.

---

## 4. 환산월세 계산

보증금이 다른 월세 계약을 같은 기준으로 비교하기 위해 보증금을 월세로 환산.

연 환산율은 5%로 고정.

```text
환산월세(만원) = 월세(만원) + 보증금(만원) × 0.05 ÷ 12
```
환산율 5%는 팀 공통 분석 기준.

---

## 5. 자치구별 집계 기준

각 연도와 자치구별로 다음 값을 계산.

| 변수 | 기준 |
|---|---|
| `월세_계약건수` |월세 계약 수 |
| `월세_중앙값_만원` | 월세의 중앙값 |
| `보증금_중앙값_만원` | 보증금의 중앙값 |
| `환산월세_중앙값_만원` | 개별 계약의 환산월세를 먼저 계산한 후 구한 중앙값 |
| `임대면적_중앙값_m2` | 임대면적의 중앙값 |

평균은 이상치의 영향을 크게 받을 수 있으므로 중앙값을 사용.

---

## 6. 변화 추이 계산

자치구별 환산월세 중앙값을 기준으로 연도별 구간을 비교.

- 2021년 → 2023년
- 2023년 → 2025년
- 2021년 → 2025년

변화액과 변화율 계산:
```text
변화액 = 비교연도 환산월세 - 기준연도 환산월세

변화율(%) = 변화액 ÷ 기준연도 환산월세 × 100
```

변화율이 양수이면 환산월세가 증가, 음수이면 감소.
