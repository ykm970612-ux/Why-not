## 2. 분석 대상

생활물가 데이터에는 전통시장과 대형마트 자료가 포함.

대형마트 자료는 일부 자치구에만 존재하여 25개 자치구를 동일한 조건으로 비교하기 어렵기 때문에 이번 분석에서는 전통시장 자료만 사용.

분석 조건

- `년도-월`이 2025년인 자료
- 시장 유형이 `전통시장`인 자료
- 가격이 0원보다 큰 자료
- 서울시 25개 자치구에 모두 존재하는 월·품목

---

## 3. 전처리 기준

### ① 필요한 열 선택

다음 열만을 사용.

- `시장/마트 이름`
- `품목 번호`
- `품목 이름`
- `가격(원)`
- `년도-월`
- `시장유형 구분(시장/마트) 이름`
- `자치구 이름`
- `점검일자`

### ② 중복 제거

선택한 열의 값이 모두 동일한 행은 중복으로 판단하여 한 행만 남김.

### ③ 문자열 정리

시장명, 품목명, 자치구명 등 문자형 값의 앞뒤 공백을 제거.

### ④ 자료형 변환

- `품목 번호`: 숫자형
- `가격(원)`: 숫자형
- `점검일자`: 날짜형

숫자나 날짜로 변환할 수 없는 값은 결측치로 처리.

### ⑤ 결측치 처리

다음 열 중 하나라도 결측치이면 해당 행을 제외.

- `품목 번호`
- `품목 이름`
- `가격(원)`
- `자치구 이름`
- `점검일자`

---

## 4. 자치구·월·품목별 대표가격

같은 자치구에서 같은 달에 같은 품목이 여러 번 조사될 수 있으므로 가격의 중앙값을 대표가격으로 사용.

```text
자치구 품목 중앙가격 = 같은 자치구·월·품목 가격의 중앙값
```

평균은 일부 지나치게 높거나 낮은 가격의 영향을 크게 받을 수 있으므로 중앙값을 사용.

---

## 5. 공통 품목 선택

자치구마다 판매되는 품목이 다르면 물가지수를 공정하게 비교하기 어려움.

따라서 각 월을 기준으로 서울시 25개 자치구에 모두 존재하는 품목만 비교에 사용.



---

## 6. 서울 품목 기준가격

같은 월·같은 품목에 대한 25개 자치구의 대표가격 중 중앙값을 서울 기준가격으로 사용.

```text
서울 품목 기준가격 = 25개 자치구 품목 중앙가격의 중앙값
```

---

## 7. 품목 물가지수 계산

각 자치구의 품목 가격을 서울 기준가격과 비교하여 품목 물가지수를 계산.

```text
품목 물가지수 =
자치구 품목 중앙가격
÷ 서울 품목 기준가격
× 100
```

해석 기준은 다음과 같다.

- `100`: 서울 기준가격과 동일
- `100 초과`: 서울 기준보다 비쌈
- `100 미만`: 서울 기준보다 저렴함


---

## 8. 월간 생활물가지수

자치구별 월간 생활물가지수는 해당 월에 사용된 공통 품목 물가지수의 중앙값으로 계산.

```text
월간 생활물가지수 = 자치구별 공통 품목 물가지수의 중앙값
```


| 이름 | 설명 |
|---|---|
| `자치구명` | 서울시 자치구 이름 |
| `년도-월` | 분석연월 |
| `생활물가지수` | 해당 월의 생활물가지수 |
| `비교품목수` | 해당 월에 비교한 공통 품목 수 |

---

## 9. 연간 생활물가지수

자치구별 연간 생활물가지수는 12개월 월간 생활물가지수의 평균으로 계산한다.

```text
연간 생활물가지수 = 12개월 월간 생활물가지수의 평균
```




| 이름 | 설명 |
|---|---|
| `자치구명` | 서울시 자치구 이름 |
| `기준연도` | 2025 |
| `생활물가지수` | 12개월 생활물가지수 평균 |
| `분석월수` | 분석에 포함된 월의 수 |
| `월평균_비교품목수` | 월평균 공통 비교 품목 수 |

## 14. 해석 시 주의사항

- 서울 전체의 같은 달·같은 품목 가격을 기준으로 한 상대 지표.
- 생활물가지수가 높을수록 해당 자치구의 생활물가가 상대적으로 높은 편.
- 생활물가지수가 낮을수록 해당 자치구의 생활물가가 상대적으로 낮은 편.
- 전통시장 가격만 사용하므로 대형마트·온라인 쇼핑·편의점 가격을 대표하지 않음.
- 품목의 품질, 할인행사, 브랜드 차이는 통제하지 못함.
