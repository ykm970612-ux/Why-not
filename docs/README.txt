# 서울시 버스정류소 자치구 공간 전처리

## 입력 파일
- `선택지역_25개.geojson.json`: 25개 자치구 경계 (각 Feature의 `properties.code`, `properties.name`)
- `서울시버스정류소위치정보(20251209).xlsx`: 정류소 좌표가 포함된 원본

## 설치
```bash
pip install pandas geopandas shapely openpyxl pyogrio
```

## 실행
두 입력 파일과 파이썬 스크립트를 같은 폴더에 둔 뒤:
```bash
python seoul_bus_stop_gu_assign.py
```

경로를 직접 지정할 수도 있습니다:
```bash
python seoul_bus_stop_gu_assign.py --boundary "선택지역_25개.geojson.json" --bus "서울시버스정류소위치정보(20251209).xlsx" --outdir "결과"
```

## 처리 방식
1. 자치구 GeoJSON을 EPSG:4326으로 통일합니다.
2. 버스정류소의 `X좌표`를 경도, `Y좌표`를 위도로 읽어 Point를 생성합니다.
3. `within` 공간조인으로 각 정류소에 자치구 코드와 이름을 붙입니다.
4. 자치구 경계선 위에 놓인 점은 `intersects`로 재확인합니다. 경계선에서 복수 구에 걸리는 경우 자치구 코드 오름차순 첫 구로 단일 배정합니다.
5. 25개 자치구별 정류소 수를 집계합니다. 정류소가 없는 구도 0으로 표시합니다.

## 출력
- `버스정류소_자치구분류.csv`: 정류소별 자치구 코드/이름 포함
- `자치구별_버스정류소_집계.csv`: 25개 구별 정류소 수
- `버스정류소_자치구별_전처리결과.xlsx`: 위 결과 및 미분류/좌표오류 시트
- `버스정류소_자치구분류.geojson`: 분류된 정류소 Point
- `자치구_미분류_정류소.csv`: 정상 좌표지만 어떤 구에도 매칭되지 않은 정류소
- `좌표오류_정류소.csv`: 좌표 결측 또는 서울권 좌표 범위 밖의 정류소
- `전처리_검증요약.json`: 처리 건수 검증 정보

※ 원본 행은 삭제하지 않습니다. 같은 좌표라도 원본 행이 다르면 각각 유지합니다.
