# Why-not

## 프로젝트 개요

서울 25개 자치구의 청년 거주 집중도와 월세 주거비·생활 여건을
비교하여 불균형 후보 지역과 대안 후보 지역을 탐색한다.

## 폴더 구성

- src/: 전처리·지표 계산·분석용 Python 파일
- data/: 분석 데이터 보관 — Git 업로드 제외
- outputs/: 그래프 및 분석 결과
- docs/: 데이터 출처·변수 정의·협업 안내

## 협업 방식

- main: 최종 확인된 코드
- dev: 팀의 개발 결과를 통합하는 브랜치
- 작업 브랜치: dev에서 생성하여 개별 작업 진행
- 작업 브랜치를 GitHub에 push한 뒤, dev를 대상으로 Pull Request 생성
- 변경 내용 검토 후 dev에 병합

## 데이터 관리

- 원본 데이터는 수정하지 않는다.
- 데이터 파일은 각자의 data/ 폴더에 보관한다.
- 출처·다운로드 방법·파일명은 docs/에 기록한다.
- API 인증키는 코드나 GitHub에 올리지 않는다.
