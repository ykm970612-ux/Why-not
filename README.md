# Why-not

서울 청년 1인가구가 상대적으로 살기 좋은 지역을 찾기 위한 자치구별 데이터 분석 프로젝트입니다.

---

## 프로젝트 목적

서울 25개 자치구를 대상으로 청년 1인가구, 월세, 생활물가, 교통, 의료시설 및 생활편의시설을 비교합니다.

2025년 현재의 주거비와 생활 인프라를 중심으로 지역을 평가하고, 청년 1인가구와 월세의 2021·2023·2025년 변화를 지역 해석을 보완하는 자료로 활용합니다.

이 프로젝트는 특정 지역의 절대적인 우열을 판단하기보다 청년 1인가구의 관점에서 상대적으로 주거비 부담이 낮고 생활 여건이 좋은 지역을 탐색하는 것을 목적으로 합니다.

---

## 분석 대상

- 지역: 서울특별시 25개 자치구
- 청년 기준: 20~39세
- 가구 기준: 1인가구
- 현재 상태 분석 기준연도: 2025년
- 변화 분석 연도: 2021년·2023년·2025년
- 최종 연결 기준 컬럼: `자치구명`

## 프로젝트 구조

```text
Why-not/
├─ data/
│  ├─ raw/                 원본 데이터
│  └─ processed/           전처리 결과
├─ docs/
│  ├─ README.md            프로젝트 문서 안내
│  ├─ data_sources.md      데이터 출처
│  └─ preprocessing/       데이터별 전처리 기준
├─ outputs/                그래프와 최종 분석 결과
├─ src/
│  ├─ preprocessing/       데이터 전처리 코드
│  └─ analyze_rent_trend.py
├─ tests/                  테스트 코드
├─ .gitignore
└─ README.md
```

`data/` 폴더는 GitHub에 업로드하지 않으며 각 팀원이 자신의 컴퓨터에서 관리합니다.

## 데이터 관리 규칙

- 원본 데이터는 `data/raw/`에 보관합니다.
- 전처리 결과는 `data/processed/`에 보관합니다.
- 원본 데이터는 직접 수정하지 않습니다.
- `data/` 폴더는 GitHub에 업로드하지 않습니다.
- 모든 데이터의 자치구 컬럼명은 `자치구명`으로 통일합니다.
- 개인 컴퓨터의 절대경로를 코드에 작성하지 않습니다.
- API 키와 비밀번호를 GitHub에 업로드하지 않습니다.
- 데이터 기준이나 파일명을 변경하면 관련 문서도 함께 수정합니다.

---

## 분석 시 주의사항

- 지표는 서울 25개 자치구를 비교하기 위한 상대적인 값입니다.
- 시설 수가 많다고 해서 시설의 품질이나 실제 접근성이 반드시 좋다는 의미는 아닙니다.
- 청년 인구와 청년 1인가구 데이터는 작성 기준이 다를 수 있으므로 비율 계산 시 주의해야 합니다.
- 생활물가는 전통시장 가격을 기준으로 하며 대형마트, 편의점 및 온라인 가격을 대표하지 않습니다.
- 월세는 보증금을 월세로 환산한 값을 사용하므로 적용한 환산 기준을 함께 확인해야 합니다.
- 변화 분석은 현재 지역 평가를 대체하지 않고 2025년 결과의 해석을 보완하기 위해 사용합니다.
